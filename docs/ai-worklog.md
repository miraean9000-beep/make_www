# AI 코딩 도구 사용 기록

이 문서는 Codex 대화 중 프로젝트 결정에 사용한 발언을 발췌하고 구현 내용을 기록합니다.

1. 사용자가 기존 여행 서비스와 다른 실용적인 웹 아이디어를 요청했습니다. Codex는 중고 판매글 생성기를 제안했습니다.
2. 사용자가 “중고품판매 뚝딱좋네”라고 선택했습니다. Codex는 “물건 정보 입력 → 판매글 생성 → 수정·복사” 흐름과 홈, 판매글 만들기, 예시 메뉴를 제안했습니다.
3. 사용자가 “만들어봐”라고 요청했습니다. Codex는 바닐라 HTML·CSS·JavaScript와 Python API를 분리하고 기존 Copa Claude 호출 방식을 적용했습니다.
4. 예시 상품을 넣어 입력을 쉽게 재현할 수 있게 했습니다. 모델 응답을 JSON으로 검증하고, 출력은 브라우저의 텍스트 필드에 넣어 사용자가 편집할 수 있게 했습니다.
5. 실제 Claude 호출로 닌텐도 스위치 판매글을 생성했습니다. 긁힘과 박스 누락이 본문에 남고, 입력에 없던 작동 여부가 확인 항목에 표시되는지 점검했습니다.
