# 중고글 뚝딱 서비스 기획서

## 목적과 사용자

집에 있는 물건을 중고로 팔고 싶은 사람이 판매글 초안을 빠르게 만들도록 돕습니다. 주요 사용자는 판매 경험이 적거나 여러 물건을 한 번에 정리하는 개인 판매자입니다.

## 화면 구성

| 메뉴 | 화면 |
| --- | --- |
| 홈 | 서비스 소개와 판매글 만들기 링크 |
| 판매글 만들기 | 물건 정보 입력, 생성 상태 안내, 제목과 본문 편집, 복사, 게시 전 체크리스트 |
| 예시 | 게임기, 가구, 도서 입력 예시 |

상단 메뉴는 해당 섹션으로 이동합니다. 넓은 화면에서는 입력과 결과를 나란히, 좁은 화면에서는 위아래로 배치합니다.

## AI 기능

물건 이름과 사용 상태는 필수입니다. 희망 가격, 거래 방법, 구성품 및 기타 정보는 선택입니다. Python 서버가 입력을 검증하고 Claude에 전달합니다. 응답은 편집할 수 있는 제목과 본문, 확인할 항목을 담은 JSON입니다. 모델에는 흠집과 구성품 누락을 보존하고 확인되지 않은 가격이나 작동 여부를 추가하지 않도록 지시합니다. 사용자는 복사 전에 실제 상태와 초안을 대조합니다.

| 실패 상황 | 처리 |
| --- | --- |
| 필수값 누락 또는 길이 초과 | 입력란 확인을 안내합니다. |
| API 키 설정 누락 | 서버는 503과 사용자 안내 문구를 반환합니다. |
| AI 호출 오류 또는 잘못된 JSON | 서버는 502를 반환하고 재시도를 안내합니다. |
| AI 응답 지연 | 서버 또는 브라우저에서 대기를 종료하고 재시도를 안내합니다. |

입력과 생성 결과는 서비스 데이터베이스에 저장하지 않습니다. 판매글은 검토 후 복사해 원하는 중고거래 서비스에 붙여넣습니다.
